# Warden Alternate Class Features

**Optional variant feature packages for the [[character-options/classes/Warden|Warden]] class.**

A warden’s signature defender role rests on **Warden’s Grasp** (1st level), **Warden’s Mark** (2nd level), and **Warden’s Resolve** (3rd level). At 1st level, you may choose one of the alternate packages below to replace all three core features—and their later level improvements—with a specialized defensive, aggressive, or otherworldly style.
