As a bonus action, you conjure an ornate, Tiny Eldritch Hourglass in an empty hand. It takes any form of timekeeping device that you choose.

- It can be used as a Trinket for one Eldritch Invocation.
- When you fail a d20 roll, you can reroll it but must use the new result. After using this feature to turn a failure into a success, you must finish a short or long rest before using it again.
- While you are not Surprised or Incapacitated, you add your Pact modifier (minimum +1) to initiative rolls.

The Hourglass disappears if it is more than 5 feet from you for 1 minute, if you conjure another Hourglass, dismiss it (no action required), or die.

**Prerequisite:** None  
**Minimum level:** 3
