# Combat Rules

Combat in D&D 5e is structured around rounds, turns, and tactical positioning. This section covers core combat rules along with our table house rules.

---

## Combat Topics

| Rule                              | Summary             |
| --------------------------------- | ------------------- |
| [[rules/combat/actions-in-combat  | Actions in Combat]] | Attack, Cast a Spell, Dash, Disengage, Dodge, Help, Hide, Ready, Search, Use Object |
| [[rules/combat/attack-rolls       | Attack Rolls]]      | d20 + modifiers vs. Armor Class; natural 1s and 20s                                 |
| [[rules/combat/critical-hits      | Critical Hits]]     | 19–20 critical range; maximized base dice + bonus rolled die                        |
| [[rules/combat/damage-and-healing | Damage & Healing]]  | Damage rolls, resistance, vulnerability, temporary HP, dropping to 0 HP             |
| [[rules/combat/death-saves        | Death Saves]]       | d20 survival checks at 0 HP; 10 ft. stabilizing Medicine checks                     |
| [[rules/combat/flanking           | Flanking]]          | Flat +2 bonus to melee attacks for opposite-side positioning                        |
| [[rules/combat/cover              | Cover]]             | Half (+2), three-quarters (+5), and total cover defensive modifiers                 |
