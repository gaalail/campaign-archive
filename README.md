# Campaign Archive

A player-facing wiki for the Ra Gol'vek, Vyrun, and Curse of Strahd campaigns.
Live at https://gaalail.github.io/campaign-archive

Built with [Quartz](https://quartz.jzhao.xyz) and published through GitHub Pages.
Content lives in `content/`. Entry forms for the editor are defined in `.pages.yml`.
See `SETUP.md` for how to add content.
