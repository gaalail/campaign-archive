## How Players See This

1. Visit **Artificer** class page
2. See spell list information
3. Go to **Spells** → **1st-level** (or any level)
4. Click a spell
5. See "Available to: Artificer" (if linked) in the Related Content section
6. Can navigate back to Artificer class page
